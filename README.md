# Trabalho Telecom 2026.2 - MP3 vs. Gemini AI Benchmark

Projeto de pesquisa e engenharia de telecomunicações para analisar como diferentes tratamentos e compressões no formato **MP3** afetam a transcrição de fala por Inteligência Artificial (**Google Gemini API**).

## 🎯 Objetivos
- Avaliar o impacto de variações de **bitrates** (8k a 320k), **taxas de amostragem** (8kHz a 48kHz), **canais** (mono/estéreo) e **filtros de voz**.
- Medir métricas de **Acurácia (WER/CER)**, **Consumo de Tokens**, **Latência** e **Taxa de Compressão**.
- Formular e prototipar um perfil de áudio MP3 altamente otimizado para transcrição por IA com o melhor custo-benefício.
